# Kimi K3 design authority

Kimi K3 owns recommendations for visual and interaction hierarchy, composition, spacing, typography, accessible color use, responsive layout, component presentation, information density, navigation UX, motion, visual states, and screenshot critique.

Codex owns production edits, architecture, implementation choices, tests, browser verification, performance, accessibility implementation, persistence, data integrity, protected business logic, regression repair, documentation, and release evidence.

Kimi is a design authority, not the production implementation agent. It may challenge current UX and provide tiny illustrative snippets, but it must not broadly edit the application, restore retired product systems, or silently redefine workout, recommendation, grade, history, rest, import, or persistence behavior.

When a proposal conflicts with protected behavior, Codex preserves the behavior and implements the closest visually equivalent design. The conflict is recorded in `CODEX_REDESIGN_IMPLEMENTATION_LOG.md`.

Semantic state baseline: current blue; completed green; future neutral; skipped muted; intervention warm; stop/error red. Alternatives are welcome only when the distinctions remain accessible and immediately legible.
