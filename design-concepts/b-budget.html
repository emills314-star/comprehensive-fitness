Concept B

Budget

Training is allocation against research landmarks, so the app is built from exactly one primitive — the allocation bar — repeated fractally at every scale: a set inside an exercise, an exercise inside a session, a session inside a week, a week inside a mesocycle. The bar is the container; there are no generic cards. Colour is quantitative rather than decorative, and navigation is a zoom level instead of four peer tabs.
