Do not cite the historical values below as current performance results.

## Historical method

The 2026-07-15 development fixture used 180 submitted sessions, 1,440 exercise records, and 5,760 completed sets in Chromium at 375 px mobile and 1280 × 900 desktop viewports. Browser-control transport time was excluded.

The fixture and verbose performance output were local-development only and did not enter production.

## Current implementation considerations

- Active set edits use indexed entity lookup and bounded draft persistence.
- Submitted-history analysis and Progress are derived from source workouts without reactivating deleted analytics.
- Set completion and timer updates avoid rebuilding unrelated product surfaces.
- Normal boot loads only catalog identity compatibility; it does not load research/personal-evidence or analytical recommendation data.
- Workout cloud upload is removed, so set completion no longer creates workout-copy network work.
- The ordered classic-script runtime remains eager. M8 deletes the parallel React/Vite concept toolchain but does not claim a framework-level performance improvement.
