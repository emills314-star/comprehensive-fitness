Ten coaches. Pick one.

Ten complete reinterpretations of the app as a personal coach. Same colour palette as the shipped app, same workout, same flagged lift — everything else is different. Each one shows the coach catching a lift outside your normal and giving its next best action for today and for next session.

The same in all ten, so you're only choosing the look and feel: a Previous column · W / D / F set flags · tap the check to accept the coach's targets · rest timer that starts on the check with −15s / +15s / Skip · RPE left blank for you · coach changes to later sets shown with one reason line and Undo · a "This was a deload" switch on every exercise and on the session · "Injured, skip" only on a planned session · Fitbit as one quiet "Last night" line, no scores.

The ten directions

Each is a different answer to “what is a coach, on a phone?” Open one to see all five screens and its honest trade-off.

01

Control Chart

Every lift lives inside its own normal band. Logging a set plots it; leaving the band is the flag.

Built by SolOpen concept →
02

Earpiece

The coach talks in your ear; the screen is one huge live caption and one huge button. The flag arrives like a call.

Built by SonnetOpen concept →
03

Futures

Every decision shows the next session it creates. The coach lays out parallel futures and you pick one.

Built by SolOpen concept →
04

Sentence

The workout is one beautifully set paragraph. The coach coaches by rewriting it in front of you.

Built by SonnetOpen concept →
05

Ambient

The coach lives on your lock screen, Dynamic Island, watch and widgets. You never have to open the app.

Built by SonnetOpen concept →
06

Hypothesis

Every set is a prediction and every miss is a finding. The next best action is the next test.

Built by SonnetOpen concept →
07

Instrument

A dedicated training device with one Effort knob. The coach turns it with you.

Built by SolOpen concept →
08

Lint

The coach lints your training like code: squiggles, rule IDs, and Quick Fixes scoped to today, next time, or both.

Built by SolOpen concept →
09

Engine

Chess-engine analysis for your sets: an eval bar, annotated moves, and the best line from here.

Built by SolOpen concept →
10

Loaded Bar

The interface is the real equipment, loaded with exact plates. The coach coaches by changing what’s on the bar.

Built by SonnetOpen concept →
