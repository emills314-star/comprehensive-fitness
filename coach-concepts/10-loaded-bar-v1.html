Coach concept 10 · built on the v1 engine

Loaded Bar

The same bar, now showing only what the v1 coach engine decides: a start target per set, then one step on the next untouched set with one reason line.

How it feels

The set table sits right under the real equipment, loaded exactly to the active set's target. When the engine changes a load, the bar changes with it and the plate swap is spelled out.

How the coach speaks

In the engine's own sentences, word for word, on a one-line tag hung from the collar. It says nothing the rule did not decide.

The trade-off

v1 is quieter than the first concept: no statistical flag, no ranked causes, no options, no changes to other lifts or weekly volume. A rep step moves no plates, so the bar only changes when the load does.

This page is v1 behaviour, not a wish list.
